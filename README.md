# Remi — Persistent Personal LLM Agent

## 中文

### 目前能力

- macOS 桌面常驻角色：透明、置顶、可移动，并支持切换 Pet Pack。
- 统一 Agent Runtime：聊天与自主 Heartbeat 都经过同一运行时处理。
- OpenAI-compatible 模型接入：可配置 Provider、模型与 API 地址。
- 持久身份与状态：支持可编辑的 `SOUL.md`、Pet State 和上下文构建。
- 长期记忆：支持 Working、Semantic、Episodic 和 Relationship Memory，重启后仍可保留。
- 记忆控制：可以查看、修正、置顶、归档、恢复和删除记忆。
- 主动行为：可在本地规则约束下保持安静、移动、睡眠或主动交流。
- Companion Profile：可以导出和导入身份、记忆、关系及行为设置，不包含 API Key。
- 可追踪运行：记录 event、action、memory operation 和 LLM trace。

### 未来方向

- 研究长期记忆的修订、替代、巩固和遗忘机制。
- 改进 Heartbeat 的主动行为策略与用户偏好适配。
- 增加更丰富的角色外观、动画和跨平台支持。
- 探索语音交互、外部工具接入和更完整的隐私控制。
- 完善 macOS 签名、公证和正式发布流程。

## English

### Current capabilities

- A persistent macOS desktop character with a transparent, always-on-top window, local movement, and switchable Pet Packs.
- A unified Agent Runtime for both user chat and autonomous heartbeat decisions.
- Configurable OpenAI-compatible providers, endpoints, and models.
- Persistent identity and state through an editable `SOUL.md`, Pet State, and context builder.
- Working, Semantic, Episodic, and Relationship Memory that survives application restarts.
- User controls for inspecting, correcting, pinning, archiving, restoring, and deleting memories.
- Proactive behavior governed by local preferences, quiet hours, cooldowns, and interaction limits.
- Companion Profile export and import for identity, memory, relationships, and behavior settings without API keys.
- Trace recording for events, actions, memory operations, and LLM activity.

### Future directions

- Study how long-term memory should be revised, superseded, consolidated, and forgotten.
- Improve heartbeat policies and adaptation to individual user preferences.
- Add richer character appearances, animation systems, and cross-platform support.
- Explore voice interaction, external tools, and stronger privacy controls.
- Complete the macOS signing, notarization, and release workflow.
